Cloudflare Tunnel

          

          

            
          

          
本机无公网 IP 时，用 cloudflared 把本地节点映射为公网 HTTPS 地址（需已安装 cloudflared）。模式优先级：token 远程隧道 > 命名隧道（hostname+uuid+凭据文件）> 快速隧道。

保存后立即生效。接口令牌可在顶栏填写（管理员令牌完全访问；普通用户令牌仅可转换与拉取订阅）。

        

        

          
模板管理

          

            
            
            
          

          
          

            Clash 模板占位符：{{proxies}} / {{proxy-groups}} / {{rules}} / {{name}}；
            规则模板占位符：{{proxy}}（替换为手动选择组名）。保存后立即生效。
          

        

      


      
      

        
数据备份与迁移

        
导出当前全部运行时数据（覆盖配置 + 自定义模板 + 隧道凭据等），可下载保存；在另一台机器导入即可快捷迁移。备份包含令牌等敏感信息，请妥善保管。

自定义规则 · 从节点池取节点 高级▼

可用规则：include / exclude（名称正则）、type（节点类型）、country（国家，如 JP/HK/US）、 source（来源域名包含）、latency（延迟上限 ms）、speed（速度下限 B/s）、sort（排序）、limit（数量上限）。 规则默认开启，每条规则可加 "enabled":false 单独停用；停用节点不参与订阅输出，可加 "include_disabled":1 临时包含。 生成的链接即可在 Clash / sing-box 等客户端直接订阅。

质量门槛 · 按指标自动开关节点 高级

质量指标：alive（可用性）、latency（延迟 ms）、speed（速度 B/s）、score（质量分 0-100： 可用性 40 + 延迟 30 + 速度 30）、name（名称排除）。不合格节点自动停用、合格节点自动启用，结果持久化。 在「全站参数 → 节点池」开启 pool.quality_enabled 后，每次测速完成自动应用；「立即应用」可手动强制执行。 未测节点默认放行（pool.quality_default_pass 可调）。

自动清理 · 自定义删除逻辑 高级

删除规则：unreachable（不可达）、stale（超 N 天未更新）、no_probe（入库超 N 天未测速）、 latency（延迟超上限）、speed（速度低下限）、score（质量分低）、name（名称正则）、source（来源包含）。 默认关闭（保留全部节点）；在「全站参数 → 节点池」开启 pool.cleanup_enabled 后，每次测速/刷新自动清理； 「立即清理」可手动强制执行。

保存后点击「重启本地节点与隧道」即可让端口 / 启用状态生效。启用前请务必设置认证，避免成为开放代理。

Cloudflare Tunnel Web 页面 / API 入口

三种用法（按需选一种）：
① 系统服务方式（推荐，已在服务器装好）：在服务器执行 cloudflared service install 令牌 装成系统服务，隧道自动连上 CF； 域名 → 本地服务的映射在 CF 面板「Zero Trust → Tunnels → 你的隧道 → Public Hostname」配置（Service 选 HTTP，URL 填 localhost:8080）。 此时下方「启用 CF 隧道」保持关闭即可，避免两套隧道同时运行。
② 远程管理令牌（应用内启动）：把 CF 面板生成的 JWT 令牌（eyJhIjoi...）填入「远程管理隧道令牌」，应用自动连同一隧道；映射仍在 CF 面板配置。
③ 命名隧道：已有 cloudflared tunnel create 的隧道时，填「命名隧道域名 + UUID + 凭据文件路径」，应用内自启隧道（适合程序化部署，不依赖系统服务）。
注意：隧道只转发 HTTP(S) 请求，本机代理节点（CONNECT）会被 CF 边缘拦截；代理节点请用服务器直连端口（SOCKS5/HTTP）。

本机无公网 IP 时，用 cloudflared 把本地节点映射为公网 HTTPS 地址。模式优先级：token 远程隧道 > 命名隧道 > 快速隧道。
